Sobre esta Aplicação

1. Arquitetura MVT do Django

O Django utiliza o padrão MVT (Model-View-Template):

  • Model: Gere a base de dados e a estrutura dos dados.
  • View: Contém a lógica de negócio e decide o que mostrar ao utilizador.
  • Template: É a parte visual (HTML) que o utilizador vê.

2. Modelação

A estrutura da base de dados foi desenhada para suportar as entidades do portfólio (Projetos, UC, Tecnologias, etc.).

Código models.py

from django.db import models

class TipoTecnologia(models.Model):
    nome = models.CharField(max_length=100)

class Tecnologia(models.Model):
    nome = models.CharField(max_length=100)
    tipo = models.ForeignKey(TipoTecnologia, on_delete=models.SET_NULL, null=True)
    descricao = models.TextField(blank=True)
    # ... restantes campos
